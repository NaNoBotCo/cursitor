Cursitor

A litigation desk for Claude Code. Short file links, deadlines that show their arithmetic, pleading paper, exhibits and OCR — for one person with one case, or a firm of fifteen.

01

Pasteวาง

Paste a lawsuit copied out of a PDF, Word file, email or court website. Cursitor removes line numbers, running headers and page footers, mends hyphenation, rejoins paragraphs, and sets the result on California pleading paper: 28 numbered lines, double rule, caption, footer.

วางคำฟ้องที่คัดลอกมาจาก PDF ไฟล์ Word อีเมล หรือเว็บศาล Cursitor ลบเลขบรรทัด หัวกระดาษ ท้ายกระดาษ ต่อคำที่ถูกตัดยัติภังค์ ต่อย่อหน้าให้ แล้วจัดลงกระดาษคำฟ้องแบบแคลิฟอร์เนีย 28 บรรทัดมีเลข เส้นคู่ หัวคดี และท้ายกระดาษ (เอกสารตัวอย่างเป็นภาษาอังกฤษตามแบบศาลสหรัฐ)

Rule tables carry their citations, for checking each date against the current code, the local rules and the court's own holiday calendar.

        04
        
  
        Linksลิงก์
        
  
        Court files carry long names with em-dashes, brackets and commas. Pasted into a browser, the path turns into a wall of percent signs. Cursitor keeps a folder of short ASCII links that point at the files, gives every file in an answer as one of them, and re-points the link when a file is renamed or moved.
        
  
        ไฟล์คดีมีชื่อยาว มีขีดยาว วงเล็บ และจุลภาค วางลงเบราว์เซอร์แล้วกลายเป็นเครื่องหมายเปอร์เซ็นต์เต็มบรรทัด Cursitor เก็บโฟลเดอร์ลิงก์สั้นภาษาอังกฤษล้วนที่ชี้ไปยังไฟล์จริง ทุกไฟล์ในคำตอบมาเป็นลิงก์สั้น และเมื่อย้ายหรือเปลี่ยนชื่อไฟล์ ลิงก์ก็ชี้ตามไป
