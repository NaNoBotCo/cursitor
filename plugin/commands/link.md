---
description: "Short ASCII paths for files with long names"
argument-hint: "add <path> [short-name] | list | prune | mv <old> <new>"
---

Run `"${CLAUDE_PLUGIN_ROOT}/scripts/cursitor" link $ARGUMENTS` with the Bash tool. Give the printed short path to the person as a plain path, without a file:// prefix. When renaming or moving a linked file, use `link mv` so its links follow it in the same step. Run `link list` before finishing a build and fix any DEAD line.
